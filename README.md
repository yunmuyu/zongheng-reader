# 纵横四海 · 阅读工作台（最终发布版）

打开 `index.html` 即可阅读。网页默认带有 V3 工作台的 176 条内容，图片使用原始导出中的 CDN 地址。

## 导入 ZIP

点击顶部「导入 ZIP」，可以直接导入：

- 即刻原始导出 ZIP：包含 `all_posts.json`、`posts/**/post.json` 和图片。
- AI 阅读包 ZIP：包含 `data.json`。

网页不会把你的个人 ZIP 固定打包进发布版；直接把本机导出的 ZIP 上传到「导入 ZIP」即可。

目前支持：即刻原始导出 ZIP、AI 阅读包 ZIP（`data.json`）和 V3 完整工作台 ZIP。导入后的内容会替换当前时间流，图片会在浏览器本地解压并立即可读。

已读、收藏、待实践、高亮和批注会继续保存在本机；同一条内容再次导入时，已有阅读状态会继续沿用。

## GitHub Pages

这是一个纯静态页面，不需要构建步骤。Pages 使用 `main` 分支根目录即可。

本地阅读状态保存在浏览器 `localStorage`。从本地文件切换到 Pages 后，如需迁移状态，请在旧页面使用「导出 → 3 完整状态 JSON」，再在 Pages 页面使用「导出 → 7 导入之前的 JSON 状态」。
